# Upstream PR archive

Snapshot taken 2026-11-14 from gts360/django-mcp-server, all 28 PRs returned by the GitHub API across all pages and states.
`pulls.json` indexes original authors, URLs, bodies, open/closed/merged state and head SHAs.
Each `pulls/<number>/` contains raw PR details, comments, review submissions, inline comments, timeline, commits, files and patch.
Paginated JSON files are arrays of API pages. Raw timestamps and logins preserve attribution.
GitHub user accounts, PR numbers, review approvals and CI statuses cannot be migrated as native historical events: this is an archive.
Draft PRs in the successor are new maintainer-created review requests with original attribution and links.
Only still-available PR refs can be imported; archive manifests record exact refs and checksums.
